# Просмотр Markdown

Markdown отображается прямо в Neovim с помощью `render-markdown.nvim`:
заголовки, списки, таблицы и блоки кода оформляются автоматически при открытии
файла `.md`. В режиме вставки доступна исходная разметка; строка под курсором
также раскрывает разметку для редактирования.

- `Space`, `t`, `m` или `:RenderMarkdown toggle` — переключить отображение.
- `:RenderMarkdown preview` — открыть предпросмотр рядом.
- `:checkhealth render-markdown` — проверить настройку плагина.

Плагин устанавливается через `vim.pack`, его версия закреплена в
`nvim-pack-lock.json`. Парсеры `markdown` и `markdown_inline` устанавливаются
Treesitter при любом профиле `NVIM_LSP`. Иконки используют существующий
`nvim-web-devicons` и Nerd Font терминала.

Проверено на Neovim 0.12.6: запуск с Markdown-файлом, наличие обоих парсеров,
инициализация и переключение рендеринга. Проверка здоровья подтверждает
корректность конфигурации, Markdown-парсеров и источника иконок.
Предупреждения об отсутствующих `html`, `latex`, `yaml` и конвертере формул
относятся к дополнительным возможностям: HTML-комментариям, формулам и YAML
frontmatter. Для обычного Markdown эти зависимости не требуются.
